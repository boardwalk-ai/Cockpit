Install

Android 8 or newer.

Download

Tap Download on the build you want. Your browser may warn about APK files — keep the file.

Allow the install

Open the file. Android asks to allow installs from your browser once — allow it, then tap Install.

Sign in

Sign in with your Google account. Only accounts on the test list get in; ask the team if you're not.

Going back to an older version? Android won't install an older build over a newer one. Uninstall Octopilot first, then install the older build. Your studios, essays and credits live on the server and come back when you sign in.
